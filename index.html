01 · About

Backend-first, security-curious.

Stacy — Trixie to teammates — is a software developer from Egerton University. Most of her recent work sits at the backend: API design, state machines, ledgers, and authentication, with React on the frontend when a project calls for it.

She currently works on Sentinel, a compliance and identity-verification platform, where she's leading a backend migration to Convex — scaffolding the schema, API key auth, HTTP routes, a risk-engine state machine, a credit ledger, and a webhook retry system, alongside a small team.

Outside of coursework and Sentinel, she ships personal projects end-to-end: a face-recognition access control system with real-time alerting, a multi-tenant billing platform wired into M-Pesa, and earlier full-stack builds in Django and React. In parallel, she's putting in deliberate hours on the security side — Burp Suite, Wireshark, and Splunk — working blind SQL injection labs and DNS-tunneling detection exercises to build the same instincts from the attacker's side.
